КРИТИЧНО: сначала СОЗДАЙ базу Firestore, иначе будет "Ошибка Firebase".

1. Открой: https://console.firebase.google.com/project/custom-graphics-36c50/firestore
2. Create database → Start in test mode → Enable (регион любой)
3. Rules → вставь и Publish:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}

Без шага 2 лидерборд, онлайн и выдача другим через мини-апп НЕ работают.
Выдача себе работает всегда (localStorage + CloudStorage).
Выдача другим через БОТА работает всегда (кнопка sync).
