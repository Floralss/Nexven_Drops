В Firebase Console -> Firestore -> Rules -> Publish:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}

Без этого НЕ работают:
- общий лидерборд
- онлайн
- выдача TON другим игрокам из админ-панели (коллекция grants)

Как подключить:
1. Создай проект в console.firebase.google.com
2. Firestore Database -> Create (production или test mode)
3. Project settings -> General -> скопируй projectId и Web API Key
4. Впиши их в config.js:
   projectId: 'твой-project-id',
   apiKey: 'AIza...'
5. Опубликуй rules выше
6. Задеплой сайт заново
