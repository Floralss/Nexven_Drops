НАСТРОЙКА FIREBASE (проект custom-graphics-36c50) — 2 минуты, один раз:

1) console.firebase.google.com -> проект custom-graphics-36c50 -> Build -> Firestore Database.
   Если написано "Create database" — нажми, режим Production или Test (любой), регион любой, база "(default)".
2) Вкладка Rules -> вставь это -> Publish:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}

3) Build -> Project settings -> General: убедись, что Web API key совпадает с apiKey в config.js
   (если ключ ограничен по HTTP-referrer — разреши домен GitHub Pages или сними ограничение,
   а также убедись что в Google Cloud включён "Cloud Firestore API").

Без шагов 1-2 лидерборд, онлайн и выдача игрокам НЕ работают (в приложении будет написана причина: 403 / 404).
