НАСТРОЙКА ОБЩЕГО ТОПА, РЕФЕРАЛОВ, ПРОМОКОДОВ И ВЫДАЧИ TON
1) console.firebase.google.com -> создать проект -> Build -> Firestore Database -> Create database.
2) Project settings -> General: скопировать Project ID и Web API Key в config.js (projectId, apiKey).
3) Firestore -> Rules -> вставить и нажать Publish:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}

Коллекции создаются сами: players (топ, рефералы), promos (промокоды), grants (выдача от админа).
Без заполненного config.js топ, рефералы, промокоды и выдача другим игрокам НЕ работают.

Для рефералов бот при пополнении должен открывать WebApp со ссылкой вида  ...?sync=БАЛАНС&dep=СУММА_ПОПОЛНЕНИЯ_В_TON&dt=УНИКАЛЬНЫЙ_ID_ПЛАТЕЖА
