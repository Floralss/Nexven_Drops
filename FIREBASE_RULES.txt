Firebase Console -> Build -> Firestore Database -> Create database (режим Production, любой регион).
Потом вкладка Rules -> вставь и нажми Publish:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}

Используемые коллекции создаются сами:
  players/{id}  - топ, онлайн и резервная копия баланса/инвентаря
  grants/{auto} - выдачи TON и сброс бесплатного кейса другим игрокам
  admins/{id}   - выданные админки

Без этих шагов выдача другим игрокам, админки, топ и онлайн НЕ РАБОТАЮТ.
