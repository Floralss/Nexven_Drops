ПРОМОКОДЫ — КАК СОЗДАВАТЬ И КАК РАБОТАЮТ (v25)

ГДЕ СОЗДАВАТЬ
  Мини-апп -> вкладка «Профиль» (иконка человечка) -> кнопка «Админ-панель» (видна только владельцу и админам из core.js)
  -> прокрутить вниз до блока «Промокоды».

КАК СОЗДАТЬ
  1) Код — введи свой (A-Z, 0-9, _ и -, 3-24 символа, регистр не важен) или оставь пустым — придумается сам (NXabc123).
  2) Награда:
       • «TON на баланс» — укажи сумму (например 0.5)
       • «Подарок / NFT» — выбери из списка (там весь каталог из gifts.js, с ценами)
       • «Сброс бесплатного кейса» — игрок сразу может открыть Daily case ещё раз
  3) «Сколько раз можно активировать» — общий лимит на ВСЕХ игроков (0 = без лимита).
  4) «Срок действия, дней» — 0 = бессрочно.
  5) «Создать промокод» — код скопируется в буфер обмена. Раздавай его в канале/чате.

УПРАВЛЕНИЕ
  Ниже в админ-панели список всех кодов: сколько раз использован (3/10), срок, награда.
  «Копия» — скопировать, «Выкл/Вкл» — временно отключить, «✕» — удалить.

ГДЕ ИГРОКИ ВВОДЯТ КОД
  • Профиль -> блок «Промокод»
  • Пополнить -> вкладка «Промокод» (раньше там была заглушка «Подарок»)

ПРАВИЛА
  • Один игрок — один раз на каждый код.
  • Лимит общих активаций не обойти даже при одновременном нажатии: счётчик и отметка «игрок использовал» записываются
    в Firestore одной атомарной транзакцией.
  • По умолчанию TON-коды могут создавать ВСЕ админы. Если хочешь только владельцу — в core.js поставь
    NX.PROMO_ADMINS_CAN_TON = false (подарочные коды и сброс кейса админы создают в любом случае).

FIREBASE
  Ничего дополнительно настраивать не нужно: используются те же Rules (read, write: if true) и 2 новые коллекции,
  они создадутся сами:  nx_promos (коды)  и  nx_promo_uses (кто какой код активировал).
  Их можно посмотреть/удалить в консоли Firestore.

ВАЖНО ПРО БЕЗОПАСНОСТЬ
  Rules открыты для записи всем (так сделано и раньше для баланса/выдач). Это значит, что технически подкованный
  человек может обратиться к Firestore напрямую. Для настоящей защиты деньги/промокоды надо проверять на сервере
  (в боте). Пока приложение работает без сервера — это ограничение всей архитектуры, а не только промокодов.
